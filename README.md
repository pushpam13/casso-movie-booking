# CASSO — Modern Movie Booking Website

This is a front-end version of the CASSO C++ movie-ticket booking project.

## Included features
- Register / login / logout
- Movies list with genre filters
- Movie details toast
- Book ticket flow
- Select date, theatre and show time
- Interactive 20-seat layout
- Prevents booked seats from being selected
- Up to 10 seats per booking
- Passenger name + age for every seat
- Promo code `MOVIE10` for 10% off
- Booking ID + booking summary
- My Bookings dashboard
- Transfer any booked seat to another passenger
- Cancel booking and release seats
- Browser `localStorage` persistence
- Responsive modern dark/glass UI

## Run
Open `index.html` in a browser. No backend is required for this demo.

## Important project note
This is intentionally a front-end/demo implementation. A real production site would need a backend, database, authentication system, server-side seat locking, payment gateway, and validation.
